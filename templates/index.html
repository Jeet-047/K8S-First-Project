This project demonstrates an end-to-end deployment of a Flask web application on a Kubernetes environment using Docker and a local Minikube cluster. The goal is to understand containerization, Kubernetes deployments, service exposure, and basic operational workflows in a real-world setup.

Project Workflow (High Level)

  • Application Development: Build and test a simple Flask web application locally.
  • Containerization: Create a Docker image using a Dockerfile and validate it by running the container.
  • Local Kubernetes Setup: Install and start a Minikube cluster to simulate a Kubernetes environment.
  • Image Management: Load the Docker image into Minikube or push it to Docker Hub when required.
  • Kubernetes Deployment: Define and apply a deployment YAML file to create Pods and manage replicas.
  • Service Exposure: Expose the application using a Kubernetes Service and access it via Minikube.
  • Monitoring & Debugging: Inspect Pods, logs, services, and use the Minikube dashboard for visibility.
This project serves as a foundation for understanding Kubernetes-based application deployment.
